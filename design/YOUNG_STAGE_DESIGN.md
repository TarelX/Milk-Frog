# 奶蛙桌宠：幼年期设计稿

版本：0.2  
目标：先完成一只可长期陪伴、可培养至标准形态的幼年奶蛙。完整的 QQ 宠物式生活、经济、学习与打工系统见 `QQ_PET_STYLE_PRODUCT_DESIGN.md`；本文件重点保留幼年等级、动作和成长演出规则。

## 1. 产品定位

奶蛙是一只低压力的桌面陪伴宠物。用户通过陪伴、抚摸、喂奶和完成专注任务积累成长经验；到达 Lv.10 后，由用户主动触发成长仪式，进入标准形态。

设计原则：

- 不死亡、不清档；低健康值可触发轻度生病与照料事件。
- 不设置连续签到断档损失。
- 等级是长期成长，心情和饱食度是短期反馈，两者互不扣减。
- 桌面默认保持安静；状态面板只在需要时出现。
- 幼年形态与标准形态使用独立素材，普通动作中不混用。

## 2. 核心循环

```text
陪伴运行
  -> 奶蛙自动待机、眨眼和偶尔表演
  -> 用户抚摸、喂奶或完成专注任务
  -> 奶蛙即时反馈并获得经验
  -> 解锁新动作和行为
  -> Lv.10 出现成长提示
  -> 用户点击“陪它长大”
  -> 播放成长演出并进入标准形态
```

## 3. 等级与经验

升级需求采用平缓递增曲线：升到下一级需要 `20 + 当前等级 × 10` 点经验。

| 当前等级 | 升级所需 | 到达该等级的累计经验 | 解锁内容 |
|---:|---:|---:|---|
| 1 | 30 | 0 | 待机、眨眼、抚摸、睡觉 |
| 2 | 40 | 30 | 喂奶 |
| 3 | 50 | 70 | 开心庆祝 |
| 4 | 60 | 120 | 叉腰、自信表演 |
| 5 | 70 | 180 | 桌面蹦跳漫游 |
| 6 | 80 | 250 | 胜利手势 |
| 7 | 90 | 330 | 专注陪伴模式 |
| 8 | 100 | 420 | 稀有气泡台词 |
| 9 | 110 | 520 | 成长前兆事件 |
| 10 | — | 630 | 成长仪式 |

### 经验来源

| 行为 | 经验 | 限制 |
|---|---:|---|
| 每日首次见面 | +5 | 每个自然日一次 |
| 陪伴 25 分钟 | +3 | 每日最多 6 次 |
| 抚摸 | 首次 +2，之后 +1 | 15 分钟冷却，每日最多 5 点 |
| 喂奶 | +3 | 每日最多 3 次 |
| 完成一次 25 分钟专注 | +5 | 每日最多 3 次 |
| 随机成长事件 | +2～5 | 每日最多一次 |

正常使用约 2～3 周到达 Lv.10。所有经验写入本地存档。

## 4. 短期状态

### 心情 `mood`

范围 0～100，初始 70。

- 抚摸、喂奶、完成专注会提高心情。
- 心情只在程序运行期间缓慢回归 60。
- 低于 30 时偶尔播放 `sad`；高于 80 时提高 `happy`、`victory` 的出现概率。
- 心情不影响经验获取，也不阻塞成长。

### 饱食度 `satiety`

范围 0～100，初始 70。

- 喂奶增加 30。
- 仅在程序运行期间每小时下降 4。
- 低于 25 时通过气泡表示“有点饿”，不会生病或扣经验。
- 高于 90 时拒绝继续进食，并用轻微摇摆反馈。

### 睡眠

- 用户可从右键菜单选择“睡一会儿”。
- 晚间自动表演更容易进入睡眠状态。
- 单击可以唤醒；拖拽会先唤醒再进入 `drag`。

## 5. 交互设计

| 操作 | 行为 |
|---|---|
| 单击 | 小幅弹跳并显示短气泡 |
| 双击 | 抚摸，播放 `happy` |
| 按住拖动 | 切换为 `drag`，松手后下落回弹 |
| 右键 | 喂奶、睡觉、专注、成长记录、设置、退出 |
| 托盘双击 | 显示或找回奶蛙 |
| 鼠标靠近 | 眼睛轻微朝向鼠标；低概率主动打招呼 |

桌面漫游使用单张待机素材配合水平镜像、上下位移和轻微旋转，表现为短距离蹦跳，不额外依赖走路帧。

## 6. 状态机

动作优先级从高到低：

```text
成长演出
  > 被拖拽 / 下落 / 落地
  > 喂奶
  > 用户触发反应
  > 睡眠
  > 自动表演
  > 漫游
  > 待机 / 眨眼
```

低优先级动作可以被高优先级动作打断。成长演出开始后不可被普通互动打断。

### 素材与动作映射

| 素材 | 用途 | 程序动画 |
|---|---|---|
| `idle.png` | 默认待机、蹦跳移动 | 呼吸缩放、轻微起伏 |
| `blink.png` | 眨眼帧 | 80～130ms 后回到待机 |
| `happy.png` | 抚摸、升级、专注完成 | 上跳、左右轻摆 |
| `sad.png` | 低心情、饥饿提醒 | 下沉、慢速晃动 |
| `eat.png` | 喂奶 | 杯子上下轻动、满足停顿 |
| `sleep.png` | 睡眠 | 慢呼吸、Z 粒子 |
| `drag.png` | 被鼠标拎起 | 根据拖动速度旋转 |
| `victory.png` | 升级、成就 | 两次弹跳、短暂闪光 |
| `confident.png` | 自动表演、解锁提示 | 轻微挺胸缩放 |

## 7. 成长仪式

到达 Lv.10 时设置 `growth_pending = true`，不在用户工作途中立刻变身。下次互动显示：“奶蛙好像准备好长大了。”用户点击“陪它长大”后播放约 9 秒演出：

1. `0.0–1.2s`：幼年奶蛙惊喜并进入 `happy`。
2. `1.2–3.0s`：连续三次弹跳，粒子逐渐增加。
3. `3.0–5.0s`：变成发光剪影，轮廓缓慢放大。
4. `5.0–5.25s`：白色闪光覆盖角色，切换形态资源。
5. `5.25–7.5s`：标准形态播放庆祝动作。
6. `7.5–9.0s`：显示成长纪念气泡并保存结果。

存档记录：

```json
{
  "stage": "standard",
  "level": 10,
  "experience": 630,
  "evolvedAt": "ISO-8601 timestamp",
  "growthSceneSeen": true
}
```

成长后标准形态成为默认形态；幼年期数据和纪念截图保留在成长相册。

## 8. 界面

奶蛙本体不常驻显示数值条。右键菜单中的“成长记录”打开一张小卡片：

- 当前等级与经验条
- 心情和饱食度图标
- 下一等级解锁内容
- 相处天数
- 成长相册入口

经验增加时，仅在奶蛙旁显示一次 `+3` 小气泡；同一分钟内的多次变化合并显示。

## 9. 存档与时间规则

- 存档位置使用用户本地应用数据目录。
- 每次经验、等级、喂奶和成长事件后原子保存。
- 离线期间不降低心情和饱食度。
- 日期计算使用本机时区，自然日边界为本地午夜。
- 修改系统时间不会导致经验变为负数；每日奖励以最后领取日期去重。

## 10. 第一版验收范围

- 幼年奶蛙透明显示、拖动与位置记忆。
- 九种素材状态均可正确点播。
- 自动待机、眨眼、蹦跳漫游和随机表演。
- 抚摸、喂奶、睡眠和专注计时。
- Lv.1～Lv.10 经验、解锁与本地存档。
- Lv.10 成长演出及标准形态切换。
- 托盘控制、尺寸、置顶、暂停漫游和退出。
