# 奶蛙桌面交互原型

本轮调整：默认进入桌面陪伴，奶蛙始终留在原位置。鼠标悬停或键盘聚焦角色时显示照料工具条，右键或“更多”打开菜单。

## 打开

直接打开 `index.html`，或在项目根目录运行：

```powershell
node design/ui/serve.cjs
```

浏览器访问 `http://127.0.0.1:4177/design/ui/index.html`。已打开旧版时刷新即可。

## 交互入口

- 悬浮工具条：喂食、洗澡、玩耍、睡觉、背包、更多。
- 右键菜单：小状态、学习/打工、商店、背包、成长记录、设置。
- 商店、背包和记录使用同一块按需打开的小面板，关闭或按 Escape 收起。
- 使用物品后收起面板，直接在桌面上的奶蛙身上播放反馈。
- 不常驻大窗口、侧边导航、任务栏或状态条。

## 动作改动

- 每隔约 3.2～6.6 秒自然眨眼，闭眼停留 120ms。
- 待机呼吸与轻微重心变化。
- 开心动作增加蓄力、上跳、落地挤压和回弹。
- 喂食、洗澡、学习、打工、睡眠分别使用不同节奏。
- 切换姿势保留角色节点与位置，增加 180ms 过渡。
- 拖动时根据位移倾斜，松手后回弹。
- 气泡到时自动消失；“轻柔动作”及系统减少动态效果偏好可关闭连续动作。

以上单图过渡已升级为连续帧播放：新增 17 组、136 张透明帧，手臂挥动、嘴部进食、抬杯、翻书、写字、洗澡收尾等通过逐帧素材完成。详见 `../MOTION_PLAN.md`。

## 连续动作测试入口

刷新原型，右键奶蛙 → **动作点播**，可选择 23 个动作并调节播放速度。点播默认播放完整一遍后恢复待机；正常学习、打工和睡眠按活动状态循环。喂食、洗澡、玩球、唤醒和拖拽也已接入对应连续帧。

## 本轮交付范围

浏览器内界面与交互原型。Windows 透明置顶、托盘、桌面点击穿透和原生窗口集成属于后续桌宠程序阶段。

`screenshots/` 中的页面截图来自此前的多页面方案，作为历史记录保留；当前以本原型和桌面优先方案为准。

验证命令：`node tools/verify-animations.cjs`（在项目根目录执行）。检查帧引用、PNG 规格、播放时序、一次性动作、睡眠尾段循环、预览覆盖与异步取消；交互体验由用户测试。
