# 桌面优先界面修订

依据用户测试反馈：奶蛙的主要体验是 QQ 宠物式桌面陪伴。

## 常驻内容

只有奶蛙本体。气泡临时出现，悬浮工具条按需显示，等级和数值不长期覆盖桌面。

## 操作结构

```text
桌面奶蛙
├─ 悬停：喂食、洗澡、玩耍、睡觉、背包、更多
├─ 单击：抚摸反馈
├─ 拖动：拎起、倾斜、松手回弹
└─ 右键 / 更多
   ├─ 小状态
   ├─ 学习 / 打工
   ├─ 商店
   ├─ 背包
   ├─ 成长记录
   └─ 设置
```

商店、背包和成长记录属于按需弹出的小工具窗口，使用后回到桌面陪伴。同一时刻只打开一个小面板。原先的完整奶蛙屋、侧边导航和多页面首页不再作为默认产品结构。

## 后续验证分工

开发过程中保留必要的语法、资源和核心逻辑检查。每轮完成后告知改动与入口，由用户进行交互和视觉体验测试；不再逐页自动操作浏览器。
