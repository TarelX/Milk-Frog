# 基础道具素材生成说明

生成方式：内置图像生成工具。  
风格参考：幼年奶蛙的 `eat.png`、`bath-happy.png` 以及已通过的道具素材。

## 统一约束

```text
柔和、圆润、抛光的 3D 游戏道具；暖黄色、奶油白和低饱和薄荷绿配色；
单个道具居中，方形透明画布，柔和棚拍光；无角色、文字、品牌、标签、
水印、地面和投影。
```

## 道具请求

- `milk-cup.png`：无把手奶油白圆杯，装满牛奶，匹配角色喝奶图中的杯子。
- `milk-pudding.png`：淡奶黄色圆顶布丁，配简洁薄荷绿色小碟。
- `grass-dumplings.png`：三颗柔软圆形青草团子，绿色主体带少量暖黄颗粒。
- `bubble-wand.png`：薄荷绿色圆环泡泡棒和三颗淡蓝白色珍珠泡泡。
- `bath-wash.png`：圆润薄荷绿色按压瓶，奶油白泵头，瓶身只有无文字水滴浮雕。
- `toy-ball.png`：暖黄色与薄荷绿色宽弧拼接的软质玩具球。

所有输出均为 1254×1254、32 位带 Alpha 的 PNG。
