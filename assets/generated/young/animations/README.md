# 幼年奶蛙连续动作包

- 17 组正式连续图，每组 8 张绘制帧，共 136 张透明 RGBA PNG。
- 播放画布：512×512；角色地面锚点：`(256, 462)`。
- `animations.json`：23 条时间线，包含每帧文件、停留时长、循环与循环起点。
- `catalog.js`：同一清单的浏览器版本，支持直接打开本地原型。
- `frames/`：正式拆分帧。
- `sheets/`：内置图像生成工具返回的原始连续图，按 4 列 2 行排列。
- `PROMPTS.json`：完整生成提示词、身份锁定约束与各动作要求。
- `extraction-report.json`：拆分规格和原图主体包围盒。

动作覆盖：待机、眨眼、挥手、喝奶、吃团子、吃布丁、搓洗、洗澡收尾、开心、小跳、庆祝、走路、入睡、睡眠呼吸、醒来、翻书、写字、拎起、落地、失落、暖饮、伸懒腰、玩球。多条时间线可复用同一组绘制帧。

## 素材处理

图像使用内置 `image_gen` 生成。每次请求固定为同一幼年母版下的一组相邻动作；没有使用成年形态图。

`tools/Split-AnimationSheets.ps1` 负责等格拆帧、移除脱离角色的透明边缘杂点、保留角色与独立道具、统一画布和基线。每个动作使用同一缩放比例，保留挤压和腾空。原始连续图保持保存。

玩球首版出现球从一侧跳到另一侧，已由 `play-v2` 替换；原始首版与拆分记录作为归档保留，不进入正式播放清单。

## 播放与测试

刷新 `design/ui/index.html`，右键奶蛙 → 动作点播。点播用于查看完整动作；日常喂食、洗澡、学习、打工、睡眠和拖动会自动调用相应时间线。

播放速度可设为 0.75×、1×、1.25×。普通动作结束回到待机；睡眠只在首次播放坐下动作，之后循环闭眼呼吸尾段。拖动可以打断动作，释放后播放落地时间线。

快速检查：在项目根目录运行 `node tools/verify-animations.cjs`。本轮不做逐页浏览器测试，视觉与手感由用户测试反馈。
