# 幼年奶蛙素材生成说明

生成方式：内置图像生成工具。  
基础参考：`2.png`、`2-1.png`、`2-2.png`。  
母版：`idle.png`。其余姿势均以母版作为第一身份参考。

## 统一约束

```text
幼年形态；矮、圆、胖的黄色奶蛙；圆顶头部与身体自然相连；
绿色眼圈、黑色瞳孔、短小四肢和圆脚；柔和的 3D 吉祥物渲染；
保持同一角色的眼距、颜色、比例、材质和光照；完整全身居中；
透明方形画布；不出现成年形态的浅色腹部、深色手脚或修长四肢；
无地面、投影、文字、水印、额外肢体和背景杂物。
```

## 各素材最终请求

- `idle.png`：正面中性站姿，双臂自然下垂，两脚同一基线。
- `blink-v2.png`：仅把待机母版的双眼改为自然闭合，并保留绿色眼部区域；其余内容保持不变。
- `happy.png`：双臂抬起、小幅跳跃、弯眼和张嘴笑。
- `sad.png`：头略低、手臂下垂、视线向下、轻微撇嘴。
- `eat.png`：双手捧无文字的白色小奶杯，期待地微笑。
- `sleep.png`：团子般坐姿，闭眼、歪头、双手放在肚子上。
- `drag.png`：双臂向上、双腿轻微悬垂、惊讶圆嘴，不出现外部手掌。
- `victory-v2.png`：单手比 V，另一只手自然下垂；第二版增加了透明边缘清理。
- `confident.png`：正面叉腰、自信微笑。
- `dirty.png`：在待机母版上增加少量浅灰尘迹与两团小灰尘，表情略显窘迫。
- `bath-happy.png`：开心举手，头顶、肩膀和肚子分布淡蓝白色泡泡。
- `yawn.png`：站立犯困，一只手遮住张开的嘴，保留绿色眼部区域。
- `sick.png`：围浅薄荷色围巾、双手捧暖饮，表现轻度不适。
- `study.png`：双手持无文字的薄荷绿色书本，眼睛看向书页。
- `work.png`：一手持淡蓝色夹板、一手拿短铅笔，夹板无文字。

所有输出均为 1254×1254、32 位带 Alpha 的 PNG。正式接入应用时，应在渲染层按非透明内容包围盒统一角色视觉高度和脚底锚点。

未带 `-v2` 的 `blink.png` 和 `victory.png` 保留为首轮生成记录；运行时清单选用第二版。

第二批角色素材继续以 `idle.png` 为第一身份参考，并按需要使用 `happy.png`、`sleep.png`、`sad.png`、`eat.png` 或 `confident.png` 作为姿势和道具交互参考。
